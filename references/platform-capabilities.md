# 平台能力与生命周期

## 提醒

Android 13+ 按需请求 POST_NOTIFICATIONS，说明用途、允许拒绝；设置提供应用通知和具体 channel 跳转。Android 8+ 提醒使用合适 channel。需要横幅/声音的提醒通常高重要性，核对声音、音频属性、分类和锁屏可见性。已有 channel 不能靠同 ID 重建强行覆盖用户选择。

区分总开关、channel、音量、横幅、锁屏、免打扰、精确闹钟资格与后台限制，提供真实状态及入口。精确调度按产品与系统规则采用合适机制，不能只依赖页面 setTimeout，也不用静音音频伪造后台能力。系统/厂商最终控制展示，不能保证任何状态都有横幅。

同一事件用稳定 ID 和状态，确认“我还在”、结束或过期后取消通知与调度，恢复后不重复提醒。前台/媒体服务有真实系统通知要求；“音视频启动加载中”残留应查误启动保活或未清服务，不能通过隐藏系统义务解决。

## 安放个案

本用户已决定移除移动传感器检测，改成专注会话中亮屏离开安放/用其它应用时提醒。同步删除监听、无用权限、设置和宣传；非所有产品通用要求。

息屏、亮屏、解锁、前后台不是同一事件。建立会话/屏幕/可见性状态机，不能 onPause 就断言用户玩别的应用。系统能力不足时真实降级，不宣称强制锁机。长按结束要可靠停止声音、服务和监听并返回可操作状态，保留明确退出途径。

## 相机与相册

系统拍照 Intent、Photo Picker/SAF、自建 Camera 的权限不同；不能照抄鸿蒙 CameraPicker。自建相机按需 CAMERA；系统代拍按真实方案核对。WebView 接 onShowFileChooser 并完成/取消 callback。

content URI 不是文件路径；核对 FileProvider、URI grant、生命周期和持久化权限。导入处理方向、格式/MIME、大图采样和原生/WebView 协议。读出尺寸不证明图片已渲染。照片保持本地还是上传取决于代码，不凭产品口号。

Android 10+ 按 MediaStore 范围存储，旧系统按适用权限。核对字节数、flush/close、IS_PENDING 提交及返回 URI。一次请求一个 ID、一次确定回调；不能写入成功后因刷新/超时/字段类型误报失败，也不能失败假成功或重复补写。

分享使用可授权 content URI 和 MIME。Android URI 不与鸿蒙资源 URI 混用。

## 媒体与资源

Android 用 MediaSession，鸿蒙 AVSession 是另一平台。播放器、服务、通知按钮、计时和页面使用同一事实状态；暂停/继续以播放器结果驱动，收起再展开面板不能恢复计时。资源缺失、音频焦点、定时关闭及退出统一清理。

图片空白先核对包内文件、大小写、相对路径、MIME、拦截、CSP、透明叠层、data/blob 生命周期，与可显示旧包比较。不用渐变占位冒充图片修复。

## 二维码

生成/识别协议明确 UTF-8、中文前缀、版本、压缩/编码及大小上限。旧码兼容列明格式，不能宽松接收任意输入。按需处理原图、整页截图、工具栏截图的裁剪/旋转/缩放。区分无二维码、非本应用、旧版不支持或损坏。导入先预览再合并/替换，不直接覆盖数据。
